# Airmeet

Airmeet is a browser-based video meeting app with separate frontend and backend projects.

## Run the backend

```bash
cd backend
npm install
npm run dev
```

The backend runs on `http://localhost:5000`.

## Run the frontend

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the Vite URL shown in the terminal, normally `http://localhost:5173`.

## Notes

- Allow camera and microphone permissions in the browser.
- Open the meeting URL in another browser/incognito window to test multiple participants.
- Chat supports text, emojis and files up to 5 MB.
- The UI uses a light-green Airmeet background and light-green brand logo.
